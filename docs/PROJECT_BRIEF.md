# Project Brief

## Contexto

O projeto `case-sorveteria-analytics` analisa uma base de vendas de sorvetes de 2025 para apoiar decisões de negócio voltadas ao aumento de receita.

## Escopo Inicial

- Organizar a estrutura profissional do projeto.
- Preservar dados originais em `data/raw`.
- Preparar ambiente para análise exploratória.
- Documentar fluxo, premissas e entregáveis esperados.

## Fora Do Escopo Nesta Etapa

- Análise exploratória dos dados.
- Tratamento, limpeza ou enriquecimento da base.
- Criação de dashboards.
- Geração de insights ou recomendações.
- Alteracao dos arquivos originais.

## Entregaveis Esperados

- Base tratada para consumo analítico.
- KPIs executivos de vendas.
- Dashboard em Power BI.
- Apresentação executiva com storytelling de negócio.

## Principios

- Dados brutos são imutaveis.
- Toda transformação deve ser rastreavel.
- Análises devem responder a perguntas de negócio.
- Visualizacoes devem priorizar clareza executiva.
