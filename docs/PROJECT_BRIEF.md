# Project Brief

## Contexto

O projeto `case-sorveteria-analytics` analisa uma base de vendas de sorvetes de 2025 para apoiar decisoes de negocio voltadas ao aumento de receita.

## Escopo Inicial

- Organizar a estrutura profissional do projeto.
- Preservar dados originais em `data/raw`.
- Preparar ambiente para analise exploratoria.
- Documentar fluxo, premissas e entregaveis esperados.

## Fora Do Escopo Nesta Etapa

- Analise exploratoria dos dados.
- Tratamento, limpeza ou enriquecimento da base.
- Criacao de dashboards.
- Geracao de insights ou recomendacoes.
- Alteracao dos arquivos originais.

## Entregaveis Esperados

- Base tratada para consumo analitico.
- KPIs executivos de vendas.
- Dashboard em Power BI.
- Apresentacao executiva com storytelling de negocio.

## Principios

- Dados brutos sao imutaveis.
- Toda transformacao deve ser rastreavel.
- Analises devem responder a perguntas de negocio.
- Visualizacoes devem priorizar clareza executiva.
