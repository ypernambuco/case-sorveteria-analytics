# Changelog

## v1.0.0 - Projeto Finalizado

Primeira versão concluída do projeto Case Sorveteria Analytics, com entrega completa da jornada de dados até a camada de Business Intelligence.

### Entregas realizadas

- Análise exploratória dos dados (EDA).
- Tratamento e limpeza dos dados.
- Criação da base tratada.
- Documentação de qualidade dos dados.
- Dicionário de dados.
- Padronização de nomenclatura.
- Modelagem dimensional para Power BI.
- Dashboard executivo.
- Dashboard operacional.
- Investigação da anomalia após 22/08/2025.
- Apresentação do case.

### Aprendizados do projeto

- Importância de preservar a rastreabilidade entre base bruta, dados intermediários e base tratada.
- Necessidade de documentar premissas, limitações e decisões analíticas antes de interpretar indicadores.
- Valor da modelagem dimensional para organizar métricas, dimensões e relacionamentos no Power BI.
- Relevância de investigar anomalias na fonte antes de aplicar qualquer correção ou imputação artificial.
