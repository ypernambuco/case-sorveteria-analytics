# Changelog

## v1.0.0 - Projeto Finalizado

Primeira versao concluida do projeto Case Sorveteria Analytics, com entrega completa da jornada de dados ate a camada de Business Intelligence.

### Entregas realizadas

- Analise exploratoria dos dados (EDA).
- Tratamento e limpeza dos dados.
- Criacao da base tratada.
- Documentacao de qualidade dos dados.
- Dicionario de dados.
- Padronizacao de nomenclatura.
- Modelagem dimensional para Power BI.
- Dashboard executivo.
- Dashboard operacional.
- Investigacao da anomalia apos 22/08/2025.
- Apresentacao do case.

### Aprendizados do projeto

- Importancia de preservar a rastreabilidade entre base bruta, dados intermediarios e base tratada.
- Necessidade de documentar premissas, limitacoes e decisoes analiticas antes de interpretar indicadores.
- Valor da modelagem dimensional para organizar metricas, dimensoes e relacionamentos no Power BI.
- Relevancia de investigar anomalias na fonte antes de aplicar qualquer correcao ou imputacao artificial.
